## 1. ⚠️ 需要特别留意的两个 LGPL 组件

| 组件 | 许可证 | 为什么要注意 |
|---|---|---|
| **PySide6 / shiboken6** | `LGPL-3.0-only OR GPL-2.0-only OR GPL-3.0-only` | Qt 官方绑定。**LGPL 对"分发"有额外义务**（见下） |
| **soxr**（python-soxr） | `LGPL-2.1-or-later` | 音频重采样。同上 |

**LGPL 的实际含义（关键点）**：

- **自己用**：无任何限制，随便用。
- **分发给别人（含打包成 exe）**：需要满足
  1. **必须动态链接**（不能把 Qt / soxr 静态链进你的可执行文件）——
     静态链接会触发 GPL 传染，要求你把整个程序也开源
  2. **允许用户替换该库**（LGPL 的核心诉求）——动态链接通常已满足
  3. 随程序附上许可证原文，并声明你用的是 LGPL 版本
  4. 如果你**修改过**该库本身，修改部分要公开（本项目没有修改）

> 打包时（PyInstaller / Nuitka）默认是动态链接 Qt 的，属于合规路径；
> 但要**确认没有开静态链接选项**，并把 `LICENSE` 文本一起分发。

## 3. 模型许可

模型是**独立于代码**的许可对象，必须单独看。本项目用到的都来自 k2-fsa 的 sherpa-onnx
发布仓库（`csukuangfj/*`），该组织把转换后的模型以 **Apache-2.0** 发布；
但**原始模型**可能有各自的条款，分发前建议逐个核对模型卡。

| 模型 | 原始出处 | 需核对 |
|---|---|---|
| streaming zipformer（中/英/中英） | k2-fsa / icefall 训练 | 训练数据条款 |
| SenseVoice-Small | FunAudioLLM/SenseVoice | 见模型卡 |
| Whisper large-v3-turbo | OpenAI Whisper | OpenAI 以 MIT 发布权重 |
| Whisper tiny（语种识别用） | 同上 | 同上 |
| Silero VAD | snakers4/silero-vad | 见模型卡（v4+ 为 MIT） |

**本项目不分发模型文件**（`data/models/` 在 `.gitignore` 里），
模型由用户在首次运行向导里按需下载，因此许可责任落在使用者一侧。

## 5. 复现本文数据

```powershell
# 从元数据读所有依赖的许可证
.venv\Scripts\python.exe -c "import importlib.metadata as md; print(md.metadata('proc-tap').get('License-Expression'))"

# 未声明 License 字段的包，看包内 LICENSE 文件
Get-ChildItem .venv\Lib\site-packages\pycaw*.dist-info\LICENSE
```
